# Contributing to the Portfolio Project

Thank you for your interest in contributing to this project. We appreciate issues, feature suggestions, design enhancements, and bug fixes.

## Getting Started

1. **Fork the Repository**: Create your own copy of the repository on GitHub.
2. **Clone Locally**:
   ```bash
   git clone https://github.com/KNOWNASPRATYUSH/PORTFOLIO-WEBSITE.git
   cd PORTFOLIO-WEBSITE
   ```
3. **Install Dependencies**:
   ```bash
   npm install
   ```
4. **Run Development Server**:
   ```bash
   npm run dev
   ```

## Development Workflow

- Create a feature branch: `git checkout -b feature/your-feature-name`
- Maintain zero-dependency principles where possible.
- Ensure all pages are accessible, responsive, and render cleanly.
- Test production compilation:
  ```bash
  npm run build
  ```
- Commit your changes with clear, descriptive commit messages:
  ```bash
  git commit -m "feat: describe your change"
  ```
- Push to your fork and submit a Pull Request against `main`.

## Reporting Issues

If you discover a layout issue, broken link, or enhancement opportunity:
- Open a GitHub Issue using the appropriate issue template.
- Include browser version, device type, steps to reproduce, and screenshots if applicable.

For inquiries or questions, contact **admin@knownaspratyush.online**.
