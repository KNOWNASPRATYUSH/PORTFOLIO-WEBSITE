# Security Policy

## Supported Versions

Security updates and patches are actively maintained for the latest deployment branch (`main`).

| Branch | Supported |
| :--- | :--- |
| `main` | :white_check_mark: |
| Older releases | :x: |

## Reporting a Vulnerability

We prioritize the security and privacy of this website and its users. If you discover a security vulnerability or potential issue:

1. **Do not disclose it publicly** via GitHub issues or discussions.
2. Email full technical details to **admin@knownaspratyush.online** with the subject line `[Security Advisory] Portfolio Website`.
3. Please include:
   - Description of the vulnerability.
   - Proof of concept or reproduction steps.
   - Potential impact.

## Response Process

- We will acknowledge receipt of your report within 24–48 hours.
- We will evaluate the impact and work on a fix promptly.
- Once resolved, we will deploy the patch and confirm resolution.
